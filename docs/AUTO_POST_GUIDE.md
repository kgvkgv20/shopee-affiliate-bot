# 📱 คู่มือการใช้งานระบบเชื่อมต่อมือถือ & บอทโพสต์อัตโนมัติ (Auto-Post Guide)

> โมดูล: `src/phone_sync.py` และ `src/shopee_auto_poster.py`  
> รองรับ: **Shopee Video** และ **TikTok Shop** ผ่านระบบ **Android ADB (USB & Wi-Fi ไร้สาย)**

---

## 🎯 1. การเตรียมมือถือ Android (ครั้งแรกครั้งเดียว)

### 1.1 เปิดโหมดนักพัฒนา (Developer Mode)
1. เข้าไปที่ **การตั้งค่า (Settings)** ของโทรศัพท์มือถือ
2. เลื่อนลงไปแตะที่ **เกี่ยวกับโทรศัพท์ (About phone)** หรือ **ข้อมูลซอฟต์แวร์ (Software information)**
3. มองหาคำว่า **หมายเลขบิลด์ (Build number)** ให้แตะรัวๆ ประมาณ 7 ครั้ง
4. หน้าจอจะขึ้นข้อความแจ้งเตือนว่า *"คุณได้เปิดใช้งานโหมดนักพัฒนาแล้ว"*

### 1.2 เปิดใช้งาน USB Debugging
1. ย้อนกลับมาที่หน้าการตั้งค่าหลัก เลื่อนลงมาล่างสุดจะพบเมนูใหม่ชื่อ **ตัวเลือกสำหรับนักพัฒนา (Developer options)**
2. แตะเข้าไป แล้วเปิดสวิตช์หัวข้อ **การแก้ไขข้อบกพร่อง USB (USB debugging)**
3. หากมีหน้าต่างขึ้นมาเตือน ให้กด **อนุญาต (Allow)**

## 📶 2. การเชื่อมต่อ 2 รูปแบบ

### แบบที่ 1: เสียบสาย USB (ง่ายที่สุด เสถียรที่สุด)
1. เสียบสาย USB ระหว่างมือถือกับคอมพิวเตอร์
2. บนหน้าจอมือถือจะมีหน้าต่างถามว่า *"อนุญาตการแก้ไขข้อบกพร่อง USB จากคอมพิวเตอร์เครื่องนี้หรือไม่?"*
3. ให้ติ๊กถูกที่ช่อง **"อนุญาตจากคอมพิวเตอร์เครื่องนี้เสมอ"** แล้วกด **อนุญาต (Allow)**
4. บนหน้า Web Studio คลิกปุ่ม **`📱 เชื่อมต่อมือถือ Android`** ➔ ระบบจะแสดงชื่อรุ่นมือถือของคุณทันที (เช่น `SM-S918B` หรือ `Redmi Note 12`)

### แบบที่ 2: สั่งงานไร้สายผ่าน Wi-Fi (Wireless ADB — ไม่ต้องเสียบสาย)
> **เงื่อนไข:** มือถือและคอมพิวเตอร์ต้องต่อ Wi-Fi วงเดียวกัน (เช่น Wi-Fi บ้านเดียวกัน)

1. เข้า **Developer options** ➔ เปิดหัวข้อ **Wireless debugging (การแก้ไขข้อบกพร่องไร้สาย)**
2. แตะที่หัวข้อ Wireless debugging จะแสดง **IP address & Port** เช่น `192.168.1.45:5555`
3. ในหน้าเว็บของระบบ แตะที่ปุ่มมือถือ ➔ กรอก `192.168.1.45:5555` ลงในช่องแล้วกด **"เชื่อมต่อผ่าน Wi-Fi"**
4. เมื่อต่อสำเร็จ จะสามารถสั่งงานมือถือข้ามห้องได้โดยไม่ต้องเสียบสายเลย!

## 🚀 3. การทำงานของระบบ Auto-Post

เมื่อคุณผลิตคลิปวิดีโอเสร็จแล้วในหน้า Web Studio:
1. แตะที่ไอคอน **"ดูตัวอย่าง / จัดการวิดีโอ"** บนการ์ดสินค้า
2. คุณจะเห็นตัวเลือก:
   * **`📲 ส่งเข้า Gallery มือถือทันที:`** ระบบจะนำไฟล์วิดีโอ `.mp4` ยิงผ่านสัญญาณเน็ตเวิร์ก เข้าไปเก็บไว้ในอัลบั้มรูปของมือถือทันที (`/sdcard/DCIM/ShopeeVideo/`) และสั่งรีเฟรช Android MediaScanner ทำให้วิดีโอเด้งขึ้นมาในแกลเลอรีรูปแรกสุด
   * **`🤖 Auto-Post Shopee Video:`** ระบบจะจำลองนิ้วมือคน เปิดแอป Shopee ➔ ไปที่แท็บวิดีโอ ➔ แตะเลือกคลิปแรกสุด ➔ นำแคปชัน แฮชแท็ก และลิงก์สินค้าไปวางให้อัตโนมัติ
   * **`🎵 Auto-Post TikTok Shop:`** ระบบจะสลับไปเปิดแอป TikTok และนำคลิปเข้าสู่หน้าตัดต่อและเตรียมโพสต์ให้ทันที

## 🛡️ 4. ทำไมระบบถึงปลอดภัยจากระบบตรวจจับบอท (Anti-Ban Humanizer)?

หากใช้สคริปต์ทั่วไปกดหน้าจอแบบเป๊ะๆ ซ้ำๆ แพลตฟอร์มจะตรวจจับความผิดปกติและอาจลดการมองเห็น (Shadowban) ได้ แต่ระบบนี้มี **Anti-Ban Humanizer** ในตัว:

| การทำงานของบอททั่วไป | การทำงานของ Anti-Ban Humanizer ในระบบนี้ |
|---|---|
| กดปุ่มตำแหน่งพิกัดเดิมเป๊ะ (เช่น X=500, Y=1200) | สุ่มกระจายจุดสัมผัส **Touch Jitter ±15px** เลียนแบบการเอื้อมนิ้วโป้งมนุษย์ที่ไม่มีทางจิ้มโดนจุดเดิม 100% |
| กดปุ่มต่อเนื่องทันทีโดยไม่มีดีเลย์ (0.01 วิ) | สุ่มเวลาหน่วงระหว่างขั้นตอน **Random Human Delay 1.2 – 2.8 วินาที** |
| เลื่อนฟีดเป็นเส้นตรงเป๊ะด้วยความเร็วคงที่ | เลื่อนจอด้วย **Curved Bezier Velocity** ที่มีความหน่วงตอนเริ่มและผ่อนตอนสุดเหมือนนิ้วคน |
| ยิงตัวหนังสือรวดเดียวผ่าน Clipboard API | จำลองการพิมพ์ข้อความแบบมีจังหวะธรรมชาติ |

## 🔧 5. การแก้ไขปัญหาที่พบบ่อย (Troubleshooting)

### Q1: หน้าเว็บขึ้นว่า `อุปกรณ์ออฟไลน์ หรือยังไม่อนุญาต USB Debugging (Unauthorized)`
* **วิธีแก้:** ปลดล็อกหน้าจอมือถือของคุณ แล้วมองหาหน้าต่างป๊อปอัปแจ้งเตือน ติ๊กถูกที่ *"อนุญาตเสมอ"* แล้วกดตกลง หากไม่ขึ้น ให้ถอดสาย USB แล้วเสียบใหม่

### Q2: เชื่อมต่อ Wireless ADB แล้วขึ้นว่า Connection Refused
* **วิธีแก้:** 
  1. ตรวจสอบว่ามือถือและคอมพิวเตอร์ต่อ Wi-Fi เดียวกันหรือไม่ (ห้ามใช้เน็ตมือถือ 4G/5G)
  2. หมายเลข Port ของ Wireless debugging ใน Android รุ่นใหม่จะเปลี่ยนทุกครั้งที่ปิด-เปิด Wi-Fi ให้ดูเลข Port 5 หลักล่าสุดในหน้าจอเสมอ

### Q3: คลิปส่งเข้าเครื่องแล้ว แต่เปิดในแอป Shopee ไม่เห็น
* **วิธีแก้:** บอทมีระบบรันคำสั่ง `am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE` ให้อัตโนมัติ แต่สำหรับมือถือบางยี่ห้อ (เช่น Xiaomi / Oppo) อาจต้องรอ Gallery Index ประมาณ 5–10 วินาที หรือกดปุ่มรีเฟรชในอัลบั้มภาพ
