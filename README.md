## ✨ ไฮไลต์ฟีเจอร์เด่น (Key Features)

### 1. 🔥 แนะนำสินค้ากระแสค่าคอมสูง (High-Commission Trending Explorer)
* **ไม่ต้องเสียเวลาคิดคีย์เวิร์ดเอง:** รวมสินค้าขายดีตัวท็อป 18+ รายการในไทยที่มี **ค่าคอมมิชชัน 25% – 50%**
* **บอกกำไรต่อออเดอร์ชัดเจน:** คำนวณรายได้ให้เห็นทันที (เช่น *กำไร ~฿140/ออเดอร์*) จากยอดขายจริง 10,000 – 200,000+ ชิ้น
* **1-Click Bulk Import:** ติ๊กเลือกหลายชิ้นพร้อมกัน หรือกด "เลือกทั้งหมด" แล้วดึงเข้าคลัง `🟡 รอทำคลิป` ได้ทันที
* **Gemini AI Trend Discovery:** สั่งให้ AI สแกนเทรนด์สินค้าใหม่ตามเทศกาล พร้อมคิด Hook เปิดคลิปภาษาไทยให้ทันที

### 2. 🎬 สตูดิโอผลิตวิดีโอ AI (Viral Video Engine)
* **📱 ซับไตเติลเด้งตามคำพูดสไตล์ TikTok (Dynamic Word-by-Word Pop):** ตัวหนังสือสีขาว ขอบดำหนา ไฮไลท์คำสำคัญด้วยสีส้ม Shopee ช่วยดึงดูดสายตาคนที่ดูคลิปแบบปิดเสียง (เพิ่ม Retention Rate 3 เท่า)
* **🎙️ เสียงพากย์ AI อัตโนมัติ (Edge TTS Thai):** เสียงพากย์ไทยสำเนียงธรรมชาติ สไตล์เพื่อนป้ายยา
* **🖼️ เลย์เอาต์แนวตั้ง 9:16 คุณภาพสูง:** แสดงภาพ Packshot 3 มุม คมชัด ไม่แตก ไม่หลุดสเปก พร้อมป้ายราคา และแท็กการันตีของแท้
* **⚡ 1-Click Copy Caption:** ปุ่มคัดลอก "แคปชัน + แฮชแท็กติดเทรนด์ + ลิงก์ตะกร้า" ในคลิกเดียว

### 3. 🤖 ระบบโพสต์อัตโนมัติลงมือถือ (Mobile Auto-Poster)
* **📶 สั่งงานมือถือไร้สาย (Wireless Wi-Fi ADB):** ใช้งานผ่าน Wi-Fi ในบ้านได้ทันที ถอดสาย USB ออกได้เลย
* **📲 ส่งคลิปเข้าเครื่องทันที:** ส่งไฟล์ `.mp4` ตรงเข้า Gallery มือถือในโฟลเดอร์ `/sdcard/DCIM/ShopeeVideo/`
* **🤖 Auto-Post Shopee Video & TikTok Shop:** บอทสั่งเปิดแอป Shopee หรือ TikTok บนมือถือ เลือกคลิปจากแกลเลอรี พิมพ์แคปชัน และติดแฮชแท็กให้เองแบบสดๆ
* **🛡️ Anti-Ban Humanizer 100%:** 
  * สุ่มหน่วงเวลาก่อนคลิก (1.2s – 2.8s) เพื่อไม่ให้เป็นจังหวะตายตัวของบอท
  * สุ่มเบี่ยงพิกัดการแตะนิ้ว (Touch Jitter ±15px) เลียนแบบนิ้วโป้งมนุษย์
  * ปรับความเร็วในการพิมพ์ข้อความทีละตัวอักษรแบบเป็นธรรมชาติ

### 4. 📥 ศูนย์ดึงสินค้าเข้าคลังอเนกประสงค์ (Multi-Channel Ingestion)
* **บอทสืบค้น Search Index:** พิมพ์แค่ชื่อแบรนด์ บอทจะไปสืบค้นภาพ Packshot 1024x1024 จาก Shopee CDN ให้เอง
* **Smart Link Extractor:** รองรับทั้งลิงก์สั้น `https://s.shopee.co.th/...` และลิงก์เต็ม
* **Excel / CSV Importer:** รองรับการอัปโหลดไฟล์ตารางรายการสินค้าหลายสิบชิ้นในคราวเดียว

### 5. 📦 ตัวรันโปรแกรม Desktop สำหรับแพ็กขาย (Desktop 1-Click Launchers)
* มีไฟล์ `Start-Shopee-Bot.bat` และ `Start-Shopee-Bot.ps1`
* ดับเบิ้ลคลิกเดียวเพื่อเริ่มระบบ เช็กพอร์ตชนอัตโนมัติ สร้างทางลัดบน Desktop และเปิดเบราว์เซอร์ให้ทันที
* รองรับระบบล็อกรหัสผ่าน Master Password สำหรับป้องกันผู้ใช้งานที่ไม่ได้รับอนุญาต

## 🚀 เริ่มต้นใช้งานอย่างรวดเร็ว (Quick Start)

### 1. ติดตั้ง Dependencies

```powershell
git clone https://github.com/kgvkgv20/shopee-affiliate-bot.git
cd shopee-affiliate-bot
pip install -r requirements.txt
```

### 2. ติดตั้ง FFmpeg (หากยังไม่มีในเครื่อง)

```powershell
winget install ffmpeg
```

### 3. ตั้งค่า `.env`

คัดลอกไฟล์ `.env.example` เป็น `.env`:
```powershell
copy .env.example .env
```
เปิดไฟล์ `.env` แล้วระบุค่า API Key:
```env
# Gemini API Key (สมัครฟรีที่ https://aistudio.google.com/app/apikey)
GEMINI_API_KEY=AIzaSy...

# ตั้งรหัสผ่านเข้าใช้งานโปรแกรม (ทางเลือก สำหรับแพ็กขาย)
APP_MASTER_PASSWORD=
```

### 4. สตาร์ทโปรแกรมผ่าน Web Studio GUI

**วิธีที่ 1 (แนะนำที่สุด):** ดับเบิ้ลคลิกไฟล์ `Start-Shopee-Bot.bat` ในโฟลเดอร์โปรเจกต์  
**วิธีที่ 2:** รันคำสั่งผ่านเทอร์มินัล:
```powershell
python -m uvicorn web.server:app --host 0.0.0.0 --port 8000
```
เปิดเบราว์เซอร์ไปที่: **`http://localhost:8000`**

## 📱 วิธีเชื่อมต่อมือถือ Android (USB & Wireless Wi-Fi)

ระบบรองรับทั้งการเสียบสาย USB และการสั่งงานไร้สายผ่าน Wi-Fi วงเดียวกัน:

```
[คอมพิวเตอร์ Desktop/Laptop] ── Wi-Fi (ไร้สาย) ──► [มือถือ Android (Shopee/TikTok)]
```

1. **เปิดโหมด Developer บนมือถือ:**
   * ไปที่ **การตั้งค่า (Settings)** ➔ **เกี่ยวกับโทรศัพท์ (About phone)** ➔ แตะที่ **หมายเลขบิลด์ (Build number)** ซ้ำๆ 7 ครั้งจนขึ้นว่า *"คุณเป็นนักพัฒนาซอฟต์แวร์แล้ว"*
2. **เปิด USB Debugging:**
   * เข้า **ตัวเลือกสำหรับนักพัฒนา (Developer options)** ➔ เปิด **การแก้ไขข้อบกพร่อง USB (USB debugging)**
3. **การใช้งานแบบ Wireless ADB (ถอดสายได้เลย):**
   * เชื่อมต่อมือถือกับ Wi-Fi วงเดียวกับคอมพิวเตอร์
   * เปิด **Wireless debugging (การแก้ไขข้อบกพร่องไร้สาย)** ใน Developer Options
   * ดู IP Address และ Port (เช่น `192.168.1.45:5555`)
   * ในเว็บโปรแกรม คลิกปุ่ม **`📱 เชื่อมต่อมือถือ Android`** ➔ กรอก IP:Port ➔ กดเชื่อมต่อ

## 🛡️ กฎความปลอดภัย 8 ข้อของ Shopee Video (ปลอดภัย 100%)

ระบบนี้ได้รับการออกแบบให้สอดคล้องตามเกณฑ์และนโยบายเนื้อหาของ Shopee Video:

1. **ระบุเนื้อหา AI:** หน้าต่างของระบบมีปุ่มย้ำเตือนให้แตะเลือก "สร้างโดย AI" ก่อนโพสต์เสมอ
2. **ไม่ละเมิดทรัพย์สินทางปัญญา:** ดึงเฉพาะรูป Packshot สินค้าทางการจากแบรนด์ ไม่แอบอ้างรูปรีวิวลูกค้าท่านอื่น
3. **ไม่ใช้ AI เจนภาพเด็กหรือบุคคลสาธารณะ:** คอนเทนต์เน้นตัวสินค้า จุดเด่น ฟังก์ชัน และราคาโปรโมชั่น
4. **ไม่ Overclaim หรืออวดอ้างสรรพคุณเกินจริง:** พรอมต์ของ Gemini ถูกตั้งค่าความปลอดภัยระดับเข้มงวดเพื่อหลีกเลี่ยงคำต้องห้าม
5. **Humanized Delay:** ไม่ยิงรัวจนเซิร์ฟเวอร์ตรวจจับพฤติกรรมบอท
